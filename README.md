# Personal Portfolio

A responsive personal portfolio website showcasing my background, education, skills, projects, achievements and contact information.

**Live site:** https://mypersonal-portfolio-topaz.vercel.app

## Sections

| Section | What it shows |
| --- | --- |
| Home | Name, introduction and availability |
| Quick Facts | Answers to common questions about opportunities and availability |
| About Me | Short introduction and educational background |
| Skills | Technical and programming skills |
| Projects | Projects I've built |
| Achievements | Certificates and awards |
| Contact Me | Email, phone, location and professional links |

## Built with

- [Next.js](https://nextjs.org/) (React, TypeScript)
- [Tailwind CSS](https://tailwindcss.com/)
- Deployed on [Vercel](https://vercel.com/)

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

All personal content lives in [`src/data/profile.ts`](src/data/profile.ts). The profile photo goes in `public/` and certificate images go in `public/certificates/`.
